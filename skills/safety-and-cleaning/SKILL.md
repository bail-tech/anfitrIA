# Safety and cleaning

## Inputs
A checklist the host confirmed: smoke/CO detectors, fire extinguisher, first-aid kit, emergency exits, cleaning steps between stays, linen washing temperature, contactless check-in, and anything else they do.

## Rules
- Describe only items the host confirmed. Never claim a certification, protocol name or standard the host did not confirm.
- Reassuring, plain language; no fear-based wording.
- Unknown items become `[CHECK: ...]`, never assumptions.

## Output
A short section (under ~700 characters) for the listing, and a longer version for the house manual.
