# Repeat guests

## Who
Only past guests with `marketing_ok` (they agreed to promotional messages). Everyone else is excluded, without exception (GDPR; WhatsApp marketing templates also require opt-in).

## Message
- One detail from their stay, the season or event that makes a return worthwhile, and how to book (direct link if the host has one).
- Any offer only if the host defined it; never invent discounts.
- Under ~400 characters, in the guest's language, with an easy way to opt out.

## Output
One draft per guest, for approval, plus the list of guests skipped and why.
