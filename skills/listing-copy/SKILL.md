# Listing copy

## Pieces
- **Title**: lead with the strongest reason to book. The character limit is checked in code (the platform limit, usually 50); give 5 options.
- **Opening** (what guests see before "Show more"): 2-3 lines with the hero feature, the location benefit, and who it suits.
- **Full description**: concrete features first, then the space, location and getting around, then honest limits (stairs, street noise, no lift).
- **Guest-type version** on request: remote workers, families, couples, groups.

## Rules
- Every claim must come from the knowledge, amenities or the host's top features. Missing facts become `[CHECK: ...]`.
- The top features must appear in the title or opening, in the description, and in the amenities list; report any that are missing from one of them.
- No superlatives you cannot back ("best", "luxury") and no private details.
- Return drafts for approval; never publish.
